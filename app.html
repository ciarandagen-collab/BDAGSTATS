🏟 Match Tab
My TeamTap My Team — search by county or club name. Club accounts auto-fill.
OppositionTap Opposition — search 1,200+ GAA clubs or type a custom name
Start game▶ Start Game — clock starts, Match Info collapses
Half time⏸ Half Time → half time report appears → ▶ Start 2nd Half
Half time reportAuto shows shooting %, kickouts, possession, discipline + key observations
Undo scoreScoreboard → ↩ Undo
✍️ Record Tab
My Team / OppGreen column = My Team · White column = Opposition
Record shotTap team button → select outcome → tap zone or Skip Zone
Tag playerTap player name in outcome panel BEFORE selecting outcome
Foul / cardTap Discipline heading to expand
SubstitutionTap Substitutions heading → + Record Substitution
👥 Squad Tab
Add playerSquad sub-tab → tap empty slot → name → Save Player
Injury badgeRed dot on squad slot = active injury logged
PerformanceStats sub-tab — score per player from tagged events
Team sheetSheet sub-tab → 🖨️ Print / Save PDF

New sessionTraining → Sessions → + New Training Session
Attendance✅ Present · ❌ Absent · 🤕 Injured · 🤧 Sick · 🏆 County
Injury logTraining → Players → tap player → Injury Log → + Log Injury
ReadinessSessions → 💚 Readiness Dashboard — today's check-ins
Player linkReadiness Dashboard → 📋 Copy → share via WhatsApp
🧪 Trial Tab
New trialSquad → Trial → + New Trial
Grade sessionSessions → + New Session → score 1–10 per trialist
Multi-coachSessions → tap 📤 on session → share link with co-coaches
Sync gradesSessions → 🔄 Sync Co-Coach Grades
PromoteRankings → tap trialist → Promote → assign squad slot

Share reportHistory → 📤 Share on match card → WhatsApp / email
Season summaryHistory → 📊 Season Summary → PDF
Scout reportHistory → 🔍 Scout on match card
FixturesHistory → 📅 Fixtures → + Add Fixture
Opposition DBHistory → 🏟 Opposition DB — club profiles + notes

Open videoHistory → 🎬 Video on any match card
Tag eventSelect team → tap event button while video plays

Mark clip manuallyClips tab → ▶ Mark In → ⏹ Mark Out → 💾 Save Clip
Clip categoriesAttack / Defence / Individual / Set Piece
Share clipsClips tab → 📤 Share Clip Sheet → WhatsApp / email
