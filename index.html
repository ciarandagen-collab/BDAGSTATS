🏟 Match Tab
Set up teamsTap the Home or Away button — search by county or club name
Select competitionTap the competition button — recent picks shown at top, search to filter
Start gameGame Control → ▶ Start Game — clock starts and Match Info auto-collapses
Half timeTap ⏸ Half Time → then ▶ Start 2nd Half
Clock statusClock pulses when running · shows ⏸ Paused when stopped
Undo a scoreScoreboard → ↩ Undo Home or ↩ Undo Away (highlighted in red)
Collapse match infoTap the Match Info heading to toggle — auto-collapses on Start Game
✍️ Record Tab
Record a shotShots section → tap Shot from Play or Free → select outcome
Tag shot zoneAfter selecting outcome → tap a zone or Skip Zone
Record turnoverPossession → Turnover Forced → In Attack / Midfield / In Defence
Record a markPossession → Mark → Won or Lost
Record foul / cardTap Discipline heading to expand → Foul Given or Card
Custom eventsCustom events added in ⚙️ Settings appear automatically here
Tag a playerTap player name in outcome panel before selecting outcome
👥 Squad Tab
Add a playerTap any squad slot → enter name → tap Save Player
Performance scorePlayer Stats tab shows a score (e.g. +14) based on their tagged events
Team sheetSquad tab → Team Sheet → 🖨️ Print / Save PDF
📊 Stats & History
Save a matchStats tab → tap Save Match — banner turns green to confirm
Search historyType in the search bar at the top of History — filters by team, competition or venue
View match reportHistory tab → tap 📄 Report on any match card
Reload a matchHistory tab → tap ↩ Reload to bring it back into the tracker
Match history syncAll saved matches sync to your account — sign in on any device to restore
🎬 Video Analysis
Tag from live matchHistory tab → tap 🎬 Video on any saved match card
New video analysisHistory tab → tap 🎬 New Video Analysis → enter teams and video URL
Hide / show videoTap ▲ Hide Video to collapse video and give buttons more space
Tag an eventSelect Home or Away → tap any event button while video plays
Jump to a tagTap any entry in the tag list or any dot on the timeline
Export clip listTap 📋 Copy Clip List — copies all tags with timestamps to clipboard
⚙️ Event Settings
Open settings⚙️ button in the top right corner (beside ? and ⏻)
Edit an eventEvents tab → tap any event → edit label, icon, context and outcomes
Add custom eventEvents tab → tap + Add Custom Event → set label, icon, category and outcomes
Context (Live/Video)Each event can be set to Live Only, Video Only, or Live + Video
Performance scoresPerformance tab → adjust point values per outcome → tap Save
Club configClub admins — changes apply to all coaches in the club automatically
🏟 Club Feature
Create a club🏟 button → Create Club → enter name and county
Invite a coach🏟 → Members tab → share your 8-character invite code
Join a club🏟 → Join Club → enter invite code
💳 Subscription
Individual plansUpgrade → Individual → £5/month or £50/year
Club plansUpgrade → Club → £10/month or £90/year — unlimited coaches

Sign out⏻ Sign Out button — top right corner
Match historyClear browser data? Sign back in — all matches restore from your account
App not updatingDelete PWA from home screen and reinstall from Safari
